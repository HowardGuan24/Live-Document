======================================================================
数学 1｜MATH-01｜单位圆怎样生成正弦曲线
======================================================================

要讲清楚的概念：

一个点在单位圆上匀速转动，它的纵坐标随时间变化就是正弦函数。观看者应看到圆周运动、
水平投影和曲线上的当前点始终对应，而不是只看到一条已经画好的波浪线。

建议片段：

1. 点从角度 0 开始，右侧坐标纸上曲线从原点开始记录；
2. 点转到四分之一圈，纵坐标达到最大值，曲线到达第一个波峰；
3. 点经过半圈和四分之三圈，曲线依次穿过零点并到达波谷；
4. 点完成一圈，恰好画出一个周期，下一周期重复。

程序必须决定：

- 圆心、半径、角度、角速度和当前点位置；
- 当前点纵坐标与曲线上当前值的严格对应；
- 已经走过的轨迹范围，不能提前画出未来曲线；
- 坐标轴、投影虚线、角度和公式等教学叠加层。

图像与视频模型的边界：

- 图像模型可以把圆盘、转轴、指针和坐标纸做成可信的教学仪器材质；
- 精确圆、投影关系和正弦线由程序保留，不能由模型重画；
- 视频只能让点沿圆周前进并同步延长曲线，不能让圆变椭圆或让曲线相位漂移。

通用能力与硬门禁：

- 覆盖 `hard_boundary`、`object_identity`、`annotation` 和严格时间同步；
- 每一帧都要验证 `curve_y = circle_point_y`；
- 一圈只对应一个周期，轨迹长度单调增加，固定坐标系不漂移。


======================================================================
数学 2｜MATH-02｜勾股定理的拼图重排证明
======================================================================

要讲清楚的概念：

四个完全相同的直角三角形可以在同一个边长为 `a+b` 的大正方形中作两种排列。两种
排列占用的三角形面积相同，因此第一种留下的 `c²` 与第二种留下的 `a²+b²` 面积相等。

建议片段：

1. 展示四个带稳定身份的全等直角三角形和同一个外框；
2. 第一种排列形成中央边长为 `c` 的正方形；
3. 四块三角形只做平移与旋转，逐步变成第二种排列；
4. 第二种排列留下边长为 `a`、`b` 的两个正方形，并完成面积对应。

程序必须决定：

- 外框尺寸、四个三角形的边长、角度、面积和实例 ID；
- 每块拼图的刚体变换，不能拉伸或改变面积；
- 两种排列中空白区域的精确边界与面积；
- `a`、`b`、`c` 和等式等教学标记。

图像与视频模型的边界：

- 图像模型只提升木制或亚克力拼图片、桌面和柔和阴影的材质；
- 三角形轮廓、数量和最终拼法由程序像素或矢量层锁定；
- 视频必须表现四块刚体移动，不能把拼图片融化、复制或穿过彼此。

通用能力与硬门禁：

- 覆盖精确几何、对象身份、刚体运动、面积守恒与遮挡次序；
- 始终恰好四个三角形，边长和面积不变；
- 起点与终点空白面积满足程序计算的相等关系。


======================================================================
物理 1｜PHYS-01｜两个同步振源产生的水面波干涉
======================================================================

要讲清楚的概念：

两个同频、同相的点振源分别向外传播圆形水波。波峰遇到波峰或波谷遇到波谷时振幅
增强；波峰遇到波谷时振幅减小。单个波峰继续传播，但腹线和节线的位置相对稳定。

本案例使用理想线性叠加：水深均匀，两个振源等频、等振幅、同相；主要讲解片段内忽略
边界反射、黏性衰减和大振幅非线性。程序可用
`η(x,y,t) = η₁(x,y,t) + η₂(x,y,t)` 计算瞬时水面高度，并计算一段时间内的振幅包络。

建议片段：

1. 两个固定振源开始振动，两组波前尚未相遇；
2. 第一批圆形波前进入同一空间；
3. 重叠区出现可验证的增强位置和近静止位置；
4. 形成稳定干涉图样，波前仍然向外传播。

程序必须决定：

- 两个振源的位置、频率、相位和振幅；
- 每一时刻的水面高度场、局部法线和振幅包络；
- 波峰、波谷、节线、腹线以及边界反射尚未到达的有效区域；
- 教学用颜色、正负号和高亮。

图像与视频模型的边界：

- 图像模型提升透明水、反射、高光和浅水盘材质；
- 主要波场由程序高度或法线保留，不能把每条波纹都变成密集 Canny 刻痕；
- 视频让波前向外传播，不能整张纹理平移、随机呼吸或发明第三个振源。

通用能力与硬门禁：

- 覆盖 `scalar_field`、`height_or_normal`、周期相位和稀疏控制关闭策略；
- 两个振源和容器不漂移；
- 主要波峰、波谷和节点拓扑与程序相符；
- 容器反射波在主讲解时段内不能干扰观察区。


======================================================================
物理 2｜PHYS-02｜磁铁运动为什么在线圈中产生感应电流
======================================================================

要讲清楚的概念：

线圈中的感应电流取决于磁通量的变化，而不是“附近有磁铁”本身。磁铁靠近时磁通增加，
停止时即使磁通较大也没有持续感应电流，撤离时磁通减少且电流方向反转。

建议片段：

1. 磁铁远离且静止，电流表指零；
2. 磁铁沿线圈轴线靠近，磁通增加，表针向一个方向偏转；
3. 磁铁在线圈附近停止，表针回零；
4. 磁铁撤离，表针向相反方向偏转。

程序必须决定：

- 磁铁、线圈和电流表的固定身份、位置与尺度；
- 磁铁速度、磁通量、磁通变化率和感应电流符号；
- 电流表指针角度与程序电流值的对应；
- 磁场线、速度箭头和电流方向等教学叠加层。

图像与视频模型的边界：

- 图像模型提升铜线、磁铁、支架和仪表玻璃的材质；
- 线圈匝数、磁铁极性和指针状态由程序锁定；
- 视频只能沿指定轴线移动磁铁，不能改变线圈、复制磁铁或让停止阶段仍有表针偏转。

通用能力与硬门禁：

- 覆盖 `object_identity`、`vector_field`、状态符号反转和“运动—停止—反向”因果；
- 靠近与撤离阶段表针方向相反，停止阶段回零；
- 固定器材像素不应随磁铁运动而呼吸或变形。


======================================================================
化学 1｜CHEM-01｜酸碱滴定从局部变色到到达终点
======================================================================

要讲清楚的概念：

碱液滴入带指示剂的酸性溶液后，落点附近会短暂变色，混合后又消失；接近化学计量终点
时，同样一滴造成的颜色可以持续。观看者应理解颜色来自局部 pH 与混合，而不是烧杯
突然整体换色。

建议片段：

1. 滴定管、烧杯和初始无色酸性溶液处于固定状态；
2. 第一滴碱液落下，落点附近出现短暂的局部颜色羽流；
3. 搅拌后局部颜色消失，继续滴加并接近终点；
4. 最后一小滴混匀后形成持续、均匀且很浅的终点颜色。

程序必须决定：

- 滴数、加入体积、溶液总体积和液面高度；
- 酸碱物质的量、局部浓度、pH 场和混合状态；
- 每滴液体的身份、位置和颜色允许区域；
- 数值、反应式和终点提示等教学叠加层。

图像与视频模型的边界：

- 图像模型提升玻璃、液体、折射、反光和实验台材质；
- 液面、滴液位置与 pH 决定的颜色区域由程序控制；
- 视频表现液滴下落与局部混合，不能提前整杯变色、改变器材或凭空增加液体。

通用能力与硬门禁：

- 覆盖 `scalar_field`、局部混合、透明材质、体积守恒和阈值变化；
- 加液体积单调增加，液面变化与程序一致；
- 终点前颜色可消退，终点后浅色持续；器材几何保持固定。


======================================================================
化学 2｜CHEM-02｜盐溶液蒸发、过饱和与晶体生长
======================================================================

要讲清楚的概念：

水分蒸发使溶液浓度升高；达到过饱和后先出现晶核，随后溶质继续沉积到已有晶体上。
晶体不是因为“水变少”就同时铺满容器，而是经过成核和生长两个阶段。

建议片段：

1. 透明盐溶液中还没有可见晶体；
2. 水位下降、浓度上升，但仍未达到成核条件；
3. 少数记录了身份的晶核在指定位置首次出现；
4. 已有晶体逐步长大，溶液体积继续减少。

程序必须决定：

- 溶剂体积、溶质总量、浓度、饱和度和蒸发速率；
- 成核时刻、晶体数量、实例 ID、位置、尺寸和生长量；
- 溶液中与晶体中的溶质质量守恒；
- 浓度、时间和微观解释等教学叠加层。

图像与视频模型的边界：

- 图像模型提升玻璃皿、溶液、湿润晶面、折射和高光；
- 晶体数量、位置和大尺度轮廓由程序实例区域控制；
- 视频不能让所有晶体同时跳出、把晶体变成雪花，或让后帧晶体无故消失。

通用能力与硬门禁：

- 覆盖 `scalar_field`、实例生成、单调生长、相变阈值和质量守恒；
- 过饱和前晶体数为零，成核后实例身份稳定；
- 总溶质量误差低于案例配置阈值，晶体总体积不能倒退。


======================================================================
生物 1｜BIO-01｜一个动物细胞的有丝分裂
======================================================================

要讲清楚的概念：

复制后的染色体先凝缩，再排列到赤道板，姐妹染色单体分离到细胞两端，最后细胞质分裂。
重点是同一批遗传物质的复制后分配，不是把一个细胞随机变成两个细胞。

建议片段：

1. 染色体凝缩，纺锤体开始形成；
2. 所有复制染色体排列到赤道板；
3. 姐妹染色单体分离并分别向两极移动；
4. 两组染色体到达两端，分裂沟收缩并形成两个子细胞。

程序必须决定：

- 母细胞、染色体、着丝粒、纺锤极和子细胞的实例 ID；
- 染色体数量、复制关系、排列顺序和向两极的对应；
- 细胞膜、核膜、纺锤丝和分裂沟的可见状态；
- 阶段名称、方向箭头和染色体追踪高亮。

图像与视频模型的边界：

- 图像模型提升显微镜质感、细胞质、膜、染色体和景深；
- 实例数量、染色体身份与阶段拓扑由程序保留；
- 视频不能吞掉或复制染色体，不能在中途换细胞，也不能提前出现两个完整细胞。

通用能力与硬门禁：

- 覆盖大量 `object_identity`、可变形区域、分裂拓扑与一对多身份映射；
- 染色体分配必须与程序配置一致；
- 赤道排列、两极分离和胞质分裂的顺序不能颠倒。


======================================================================
生物 2｜BIO-02｜气孔保卫细胞吸水后怎样打开气孔
======================================================================

要讲清楚的概念：

保卫细胞内溶质增加会降低水势，水进入后膨压升高；由于细胞壁结构不均匀，两侧保卫
细胞弯曲，使中央气孔打开。重点不是简单把洞放大，而是溶质、水和细胞形变的因果链。

建议片段：

1. 两个保卫细胞膨压低，中央气孔接近关闭；
2. 离子进入保卫细胞，水势改变；
3. 水进入、细胞体积和膨压上升，保卫细胞开始弯曲；
4. 气孔达到稳定开放状态，气体交换方向作为教学叠加出现。

程序必须决定：

- 两个保卫细胞的身份、轮廓、壁厚差异和中央孔隙；
- 溶质水平、水势、膨压、体积和气孔面积；
- 离子、水和气体流向等不可直接看见的教学叠加层；
- 周围表皮细胞与镜头的固定状态。

图像与视频模型的边界：

- 图像模型提升叶表皮显微纹理、细胞壁、湿润感和照明；
- 两个保卫细胞轮廓与孔隙面积由程序形变场控制；
- 视频必须连续弯曲，不能把气孔画成第三个细胞或让周围表皮一起融化。

通用能力与硬门禁：

- 覆盖成对对象、受约束形变、隐变量、区域面积和教学叠加；
- 气孔面积随膨压在本片段内单调增加；
- 两个保卫细胞身份和邻接关系始终不变。


======================================================================
地理 1｜GEO-01｜曲流发展、裁弯取直与牛轭湖形成
======================================================================

要讲清楚的概念：

弯曲河道外侧流速较高并侵蚀，内侧流速较低并沉积，使弯道逐步迁移、曲流颈变窄。
洪水或持续侵蚀最终切穿狭颈，主流走更短的新河道，旧弯道两端淤堵后成为牛轭湖。

建议片段：

1. 单一弯曲河道中，外侧侵蚀与内侧沉积刚开始；
2. 弯道扩大并迁移，曲流颈逐步变窄；
3. 水流首次切穿狭颈，旧弯道仍与主河相连；
4. 新主河道稳定，旧弯道两端封闭成为牛轭湖。

程序必须决定：

- 地形、河道水域、流速矢量、侵蚀率和沉积率；
- 河岸移动、狭颈宽度、水体连通性和主流路径；
- 牛轭湖形成前后的拓扑变化；
- 流速箭头、侵蚀与沉积高亮等教学叠加层。

图像与视频模型的边界：

- 图像模型提升俯视河水、土壤、植被、湿地和岸线材质；
- 河道中心线、岸线变化和连通性由程序控制；
- 视频不能提前切断旧河道，不能凭空增加支流，也不能让整片地貌呼吸。

通用能力与硬门禁：

- 覆盖 `vector_field`、边界演化、侵蚀沉积标量场和水体拓扑变化；
- 狭颈宽度在切穿前单调减小；
- 水体连通分量和主流路径必须在正确阶段改变。


======================================================================
地理 2｜GEO-02｜地形雨与背风坡雨影
======================================================================

要讲清楚的概念：

湿润空气被山脉迫使抬升后膨胀冷却，达到饱和并形成云和降水；越过山顶后空气下沉增温，
相对湿度下降，背风坡形成较干燥的雨影区。

建议片段：

1. 湿润气流从迎风侧接近固定山地；
2. 气流沿坡抬升，温度下降并开始凝结成云；
3. 迎风坡出现主要降水，气流越过山顶；
4. 背风侧空气下沉增温，云量减少并形成干燥区。

程序必须决定：

- 固定地形高度、气流矢量、空气团轨迹和速度；
- 温度、水汽、相对湿度、云水和降水强度场；
- 凝结高度、迎风坡与背风坡的空间关系；
- 温度、湿度、风向和因果箭头等教学叠加层。

图像与视频模型的边界：

- 图像模型提升山地、云、雨、植被和大气层次；
- 地形、气流路径、云雨允许区域和干湿分区由程序控制；
- 视频不能移动山脉、让背风坡无依据持续暴雨，或让云逆着主气流移动。

通用能力与硬门禁：

- 覆盖 `height_or_normal`、`vector_field`、多个耦合 `scalar_field` 和不可见变量；
- 地形所有关键帧完全固定；
- 主要降水位于迎风侧，背风侧相对湿度和降水按程序下降。

======================================================================
缩放执行原则
======================================================================

1. 十个案例都必须先通过无需模型的 schema、状态、语义层和关键帧条件检查。
2. 不要求每一轮都生成十套昂贵候选。框架按本轮改动涉及的数据类型选择代表案例。
3. 每个学科至少保留一个固定图片回归案例；发布阶段再运行五个学科的完整代表集。
4. 一项控制策略要称为通用，必须在至少两个不同学科、但共享同一数据类型的案例上有效。
5. 视频策略要分别覆盖刚体运动、连续场传播、材料混合、对象分裂和地形拓扑变化。
6. 案例专用事实写进各自规格和 evaluator，不能进入通用核心。
7. 每个完成阶段的报告都要展示程序图、语义层、实际控制、完整提示词、raw 候选、
   composite、final、视频采样帧、硬门禁、分项评分和失败证据。
8. 相同输入、模型、配置和种子必须能复现同一生产结果；不得通过不断换种子掩盖低
   成功率。
