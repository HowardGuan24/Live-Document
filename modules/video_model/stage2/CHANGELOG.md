# Stage 2 changelog

## 0.1.0 — 2026-07-29

首个通过 Phase 6 发布协议的通用框架版本。

- 冻结十个跨数学、物理、化学、生物和地理的案例合同；
- 用同一确定性程序运行器生成并验证 490 帧程序动画；
- 根据语义数据类型选择图片路线，而不是按案例名称写分支；
- 发布“多供体稳健材质残差 + 程序允许区域”图片核心；
- 五个学科代表均通过图片门禁，三角洲历史基线文件保持不变；
- 五类运动均通过视频门禁；刚体运动和液体混合明确使用程序回退；
- 使用模型文件内嵌的真实 Gemma SentencePiece 与 ComfyUI
  `LTXAVGemmaTokenizer` 检查全部八次 LTX 提示词；
- 修复两类验证漏洞：GEO-01 状态声明与实际水体像素拓扑不一致，以及
  CHEM-01 材质步骤原样复制程序图却被旧门禁误判为成功；
- 保留所有原始候选、失败结果、控制图、提示词、模型指纹、合成结果和审计文件。

已知边界：

- 这是一套机制优先的程序图写实增强框架，不保证把每种教学图变成照片；
- 精确刚体和连续液体扩散暂不交给当前 LTX 模型自由推断；
- 有丝分裂视频的可见对象数量通过，但视频像素本身不能恢复程序中的父子实例 ID；
- Phase 6 三类新增图片回归复用已保存的 SDXL 供体，没有新增模型采样。
