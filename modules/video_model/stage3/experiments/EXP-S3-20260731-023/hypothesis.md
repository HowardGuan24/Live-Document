# EXP-S3-20260731-023

观察：L2 命中全部稀疏关键帧并降低跳变，但分离段仍生成大量波浪状洋红结构，
身份像素峰值达到起点的 2.51 倍。

假设：不再调用视频模型，直接在全部 49 个程序时间点导出 `region` 和
`object_identity`，再由同一冻结外观供体和通用 State Renderer B 渲染每帧，可以同时
保住写实材质、机制顺序和对象谱系。

证伪条件：区域不是从 1 变为 2 一次；身份质量超出冻结范围；关键时刻偏离已验收帧；
背景或相机跳变；实现需要在 State Renderer 核心写入 BIO Case ID。

预算：0 个图片模型候选、0 个视频模型候选；49 帧确定性重建。
