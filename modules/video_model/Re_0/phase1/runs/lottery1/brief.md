# Phase 1 制作摘要 · lottery1

- 输入判断：用户给出的是结构清楚的粗略流程；保留主线，仅补充曲流发展的驱动力（凹岸侵蚀、凸岸堆积）与洪水时高水位促成截弯的因果桥梁。
- 教学目标：让中学生和大学低年级学生能按时间顺序解释牛轭湖形成，并能区分活动河道、曲流颈、截弯新河道、封堵泥沙与废弃河道。
- 完整主线：较缓曲流 → 外侧水流较快、凹岸侵蚀，内侧较慢、凸岸堆积 → 弯道扩大并侧向迁移 → 曲流颈变窄 → 洪水期水位和流量上升，河水冲开最短通道 → 主流截弯取直 → 泥沙封堵旧河道两端 → 弯月形牛轭湖与主河道分离。
- 补充与省略：补充凹岸/凸岸、水流速度差异和洪水触发条件；省略科里奥利力、河床精细水动力学及牛轭湖后期沼泽化，以免偏离形成主线。
- 视觉方案：固定俯视洪泛平原，以一条拥有稳定身份的河道连续变形；蓝色表达活动水体，红色表达侵蚀，金色表达沉积，棕黄色表达封堵沙洲。右上角阶段标识和局部标注只存在于教学覆盖层，底部字幕与画面同步。
- 初步真实化判断：`realizable`。俯视河流地貌具有统一尺度、清楚空间关系和可分离覆盖层，适合后续科学真实感转换。
- 关键状态：初始缓弯、曲流扩大、狭窄曲流颈、洪水后新通道、两端封堵后的牛轭湖。
- 关键事件：曲流颈被洪水贯通，河道拓扑从单一大弯转为短直主河道加废弃弯道；随后旧河道两端淤积封堵并与主河道分离。
