过程概览

先在 96×64 网格上计算输沙、减速、沉积、出水和分流，再把状态渲染成动画。 机制状态是事实来源，渲染器不能修改机制。

配置 → 120 个机制状态 → 自动验证 → 105 个展示帧 → MP4 / GIF
