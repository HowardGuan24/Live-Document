# Phase 1 制作摘要：种子萌发到幼苗

- **输入判断**：较完整的粗略流程。用户已给出主要阶段与三项环境条件；需要补足“吸水—代谢恢复—呼吸供能—器官依次突破与定向生长”的因果桥梁，但不扩展到授粉、种子形成或成熟植株。
- **教学目标**：让学习者看清同一颗双子叶种子如何在同一块土壤中连续完成吸胀、种皮破裂、胚根与根系建立、胚芽出土、子叶展开、第一片真叶出现，并理解水、适宜温度、氧气不是装饰条件，而分别参与恢复细胞活动、维持酶促反应和有氧呼吸供能。
- **完整主线**：休眠种子与三项条件 → 水沿土壤孔隙进入种子并使其吸胀 → 酶与呼吸恢复、储藏物质开始供能 → 种皮在胚根端开裂 → 胚根先向下建立主根与侧根 → 胚轴弯钩保护胚芽穿土向上 → 子叶出土、展开并短期供给幼苗 → 第一片真叶展开，开始成为主要光合器官。
- **补充与省略**：补充有氧呼吸、根冠/根毛、向地性与向光性、子叶和真叶分工；省略激素通路、分子调控、单子叶植物差异及后续生殖生长。
- **视觉方案**：16:9 土壤剖面与延时摄影结合。镜头固定、种子身份与位置连续；水滴沿孔隙下渗，种子真实膨大与开裂，根系以路径生长，胚轴弯钩穿过地表后伸直，子叶与真叶依次展开。主体世界、教学标注、字幕分三层。
- **初步真实化判断**：`realizable`。土壤剖面、豆类种子和幼苗具有稳定的现实空间关系，主体可转为科学真实感；标签、箭头、条件卡和字幕留在独立覆盖层。
- **计划关键状态与事件**：吸胀完成；种皮破裂前/后；胚根出现前/后；胚芽出土前/后；子叶展开前/后；第一片真叶出现前/后。所有事件均预留无遮挡的稳定前后状态，精确时间最终以程序中的 `LIVE_DOCUMENT_BRIDGE` 为准。
